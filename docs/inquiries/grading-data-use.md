## 調べてわかったこと（2026-11-27）

### このアプリが使っているデータ

`Resources/courseRoutes.json`（411ルート・208山）は、次の表から作っています。

| 出どころ | 作った道具 |
|---|---|
| 日本百名山のグレーディング一覧表（長野県が十県二山系の表から抜粋して作成） | `Tools/parse_grading.py` |
| 長野県・富山県・新潟県・岐阜県が単独で公表しているグレーディング一覧表 | `Tools/parse_prefecture_grading.py` |

アプリで出しているのは、ルート名・登山口・**体力度（1〜10）・技術的難易度（A〜E）**・コースタイム・ルート長です。

### 各県の利用条件

| 県 | 分かったこと |
|---|---|
| 長野県 | サイト全体の規定で「私的使用のための複製」「引用」など著作権法で認められた場合を除き、**無断で複製・転用できない**。グレーディングのページに個別の定めはない |
| 新潟県 | 同じく、著作権法で認められた方法以外の転載・改変は**県の許可が必要** |
| 山梨県 | 同じく、無断転用不可。許諾は各ページの発信元に問い合わせる |
| 富山県・岐阜県 | サイト全体の著作権の規定を検索では見つけられなかった（未確認） |

### 判断がつかない点

- コースタイムやルート長のような**数値の事実そのもの**は、一般に著作権の対象になりにくいとされます
  （例: 岐阜県警察の利用規約は「数値データ、簡単な表・グラフ等は著作権の対象ではない」と書いている）
- 一方、**体力度・難易度は県と遭難防止対策協会が評価したもの**で、一覧表は編集物でもあります。
  どこまでが自由に使えるかは**法律の判断**で、AIが決めてよいことではありません
- 将来、買い切りの有料機能を付ける予定がある（決定記録 0003）

→ **取りまとめ役の長野県に問い合わせ、アプリでの利用の可否と条件を確かめる**のが確実です。
長野県は十県二山系の「共同グレーディング」を提案・取りまとめており、百名山の表も作成しています。

### 許可が得られなかった場合の逃げ道

- グレーディングのデータを外し、コースタイムは**標高差からの見積もり**（すでにある機能）と**利用者の手入力**だけにする

```

お世話になります。個人で iPhone 向けの登山計画アプリを開発しております。
貴課が公表されている「山のグレーディング」のデータの利用について、ご教示ください。

【利用したいデータ】
・日本百名山のグレーディング一覧表
・信州 山のグレーディング一覧表
（あわせて、富山県・新潟県・岐阜県が公表している一覧表）

【利用の方法】
一覧表のうち、ルート名・登山口・体力度・技術的難易度・コースタイム・ルート長を

・アプリは App Store で無料で公開する予定です。将来、一部の機能を有料にする可能性があります

【お伺いしたいこと】
1. 上記の利用は可能でしょうか。申請や許諾の手続きが必要でしょうか
2. 出典の表示方法に指定があれば、ご教示ください
3. 他県が公表している一覧表について、各県への確認が別途必要でしょうか

登山者の山選びと遭難防止に役立つよう、県の評価をそのまま伝える形で使わせていただきたいと考えております。
お手数をおかけしますが、よろしくお願いいたします。
```
