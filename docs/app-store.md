# App Store に載せる文面（下書き）

公開（T-006）のときに使う文面です。
注意書きの本体はアプリ内（ダウンロードする画面）にあります。ストアにも載せておくと、ダウンロードの前に読めて親切です。
経緯は [決定記録 0001](decisions/0001-gsi-offline-tiles.md) の「後から変えたこと」にあります。

## 説明文に入れるとよい注意書き

```
【オフライン地図について】
このアプリは国土地理院の地理院タイルを使っています。オフライン地図として端末に保存した地図は、
ご自身の端末の中で見るためだけのものです。保存した地図を公開・共有したり、それを使って別の地図や
資料を作ったりする場合（私的利用の範囲を超える場合）は、国土地理院への申請が必要になることがあります。
```
