## 法令・ライセンス

| 守ること | 理由 | 壊すとどうなるか |
|---|---|---|
| 地理院タイルの出典表示を画面に出す | 利用の条件 | 利用条件違反 |
| 地図タイルを端末に保存しない（現状） | 保存は「リアルタイム読み込み」に当たらず、測量法の申請が要る可能性がある | 法令違反の恐れ |
| 気象データに Open-Meteo（CC BY 4.0）の表示を出す | ライセンスの条件 | ライセンス違反 |
| 山岳データの出典（国土地理院）を出す | 利用の条件 | 利用条件違反 |

**オフライン地図（Phase 1 の残り）は、国土地理院への申請可否を確かめるまで着手しません。**
これは技術の問題ではなく、人間が判断することです。

経緯と回答は [決定記録 0001](decisions/0001-gsi-offline-tiles.md) にあります。
**この節を更新するときは、必ず決定記録のほうを先に読んでください。**

## 安全（利用者の命に関わる部分）

このアプリは山で使われます。時刻の計算を間違えると、日没後の行動につながります。

| 守ること | 理由 |
|---|---|
| 移動時間が分からないとき、「家を出る時刻」を出さない | 間に合わない計画を信じさせる。危険な側に外れる |
| 下山時刻は「見込み」と書く。「期限」と書かない | 自由設定・日の出基準では期限にならない |
| 日没に間に合わないときは赤で知らせる | 見落とすと日没後の行動になる |
| 標高差からの概算コースタイムに警告を出す | 水平距離を見ていないため、長い山では4時間以上短く出る |
| `pausesLocationUpdatesAutomatically = false` を変えない | true だと休憩後に記録が再開されない |
| `Info.plist` の `UIBackgroundModes: location` を消さない | 無いと起動時に落ちる |

## 取得できないもの（嘘を書かない）

次は**データが存在しません**。それらしい数字を出さず、取得できない旨を画面に書いてください。

- 高速道路料金の正確な値（NEXCO に公開APIが無い。概算と明示し、ドラぷらへ誘導）
- 駐車場の料金・台数（手入力のメモ欄で代替）
- 下山後に寄る場所の営業時間・定休日・料金
- 山ごはんを食べる時刻（モデルに持っていない）

## 技術

| 項目 | 決めたこと |
|---|---|
| 対応OS | iOS 17 以上 |
| UI | SwiftUI |
| 永続化 | SwiftData |
| 地図 | MapKit（オフライン対応時に MapLibre Native へ移行予定） |
| 配色 | アイコンの緑 `#066B3B`。`BrandGreen` / `BrandGreenDeep` を使い、色を直接書かない |
| 表示モード | 端末が暗所モードでも**常に白基調**（`UIUserInterfaceStyle = Light`） |
| 署名 | 無料の Apple ID（Personal Team）。**7日で期限が切れる**ので実機では再インストールが要る |

## UI の決めごと

- `.sheet` / `.alert` は `Form` / `List` の直下に付ける。`Section` に付けると壊れる
- ホーム画面は絵記号が主役、文字は補助
- 空の画面とホームで同じ山の絵を使い分ける（輪郭＝未定、塗り＝決定）。これは意図した表現
