# 決定記録（Decision Records）

**一度きりの重要な判断を、理由ごと残す場所**です。

`tasks.json` が「これからやること」なのに対し、ここは「**もう決まったこと**」です。
終わっても消しません。数年後に「なぜそうしたのか」を聞かれたときに答える資料です。

## ここに書くもの

- 外部の判断に従った結果（役所の回答、ライセンスの条件）
- 大きな技術の選択（MapKit から MapLibre へ移るか）
- やらないと決めたこと（Android は作らない、公共交通は対応しない）
- 一度もめて結論が出たこと

## ここに書かないもの

- 作業の進み具合 → `progress.md`
- やること → `tasks.json`
- 守るべき制約 → `docs/requirements.md`（決定記録の**結論だけ**を書き写す）

## 書き方

`NNNN-短い英語の名前.md` の形でファイルを作ります。番号は連番で、**欠番にしません**。
`_template.md` をコピーして使ってください。

## GitHub Issue との関係

スマホから見たいときのために、決定記録の内容を Issue へ転記することがあります。

- **正本はこのフォルダの `.md` ファイルです。** Issue は人が読むための控えです
- **AIは Issue を参照しません。** 必ず `.md` のほうを読みます
- 内容を直すときは、**`.md` を先に直してから** Issue を直します
- 食い違っていたら、**`.md` が正しい**とします

## 決めごと

- **一度書いた決定記録を書き換えない。** 判断が変わったら、新しい番号で作り、
  古いほうの `状態` を「置き換えられた（→ NNNN）」に変えるだけにします。
  書き換えると「なぜ当時そう判断したか」が消えます
- **AIは決定記録を勝手に作らない。** 人間が決めたことを記録するのがAIの仕事です
