# 0001. 地理院タイルのオフライン保存の可否

- **状態**: **回答待ち**

- **関係するタスク**: T-001、T-002

## 何を決める必要があったか

山では電波が届かない場所が多く、オフラインで地図を見られることは登山アプリの
基本機能です。Phase 1 の最後に残っている項目でもあります。

しかし、地理院タイルを端末内に保存する行為は、**測量法上の「複製」に当たる可能性**が
あります。公式ページには「端末保存」「オフライン」「キャッシュ」を名指しした記述が
見つからず、自分たちで判断できませんでした。

これは法令の判断であり、**AIが決めてよいことではありません**。
国土地理院に直接問い合わせることにしました。

## 分かっていたこと（問い合わせ前）

| 事実 | 出典 |
|---|---|
| 申請不要とされているのは「リアルタイムに読み込んで表示する」場合のみ | 承認申請Q&A Q1-12 |
| 「地理院タイル等の基本測量成果を複製する場合には、デッドコピーであっても承認可能」 | 測量成果の複製及び使用の事例集 |
| 手数料は無料。標準処理期間は7〜14日（郵送期間と休日を除く） | 承認申請Q&A Q5-1 |
| 承認を得た場合、承認番号と出所を地図の表示中つねに画面に出す義務がある | 承認申請Q&A Q5-2 |

つまり「禁止されている」のではなく「**たぶん申請が要る、そして申請は通りうる**」
という見立てでした。

### 送った文面（原文）

```
件名: 地理院タイルを端末内に保存して利用する場合の承認申請の要否について

お世話になります。個人で iPhone 向けの登山アプリを開発しております。
地理院タイルの利用について、承認申請の要否をご教示ください。

【利用するタイル】
・標準地図（std）
・淡色地図（pale）
・写真（seamlessphoto）

【現在の利用方法】
国土地理院のサーバーからリアルタイムに読み込んで画面に表示しています。
画面左下に「地理院タイル」の出典表示を常時行い、地理院タイル一覧ページへの
リンクを付けています。この利用方法は、承認申請Q&A Q1-12 により申請不要と
理解しております。

【今後行いたい利用方法】
登山では電波の届かない場所が多いため、利用者が事前に範囲を指定して、
その範囲のタイルを端末内（アプリのデータ領域）に保存し、電波のない
山中でオフライン表示できるようにしたいと考えております。

・保存されるのは利用者自身の端末内のみで、第三者への再配布は行いません
・タイルの加工や改変は行いません（そのままの画像として保存・表示します）
・保存したタイルを別のサーバーへ転送することはありません
・アプリは App Store での公開を予定しております（無料／一部有料機能）

【お伺いしたいこと】
1. 上記のオフライン保存は、測量法に基づく承認申請が必要でしょうか
2. 必要な場合、第29条（複製）と第30条（使用）のどちらに当たりますでしょうか
3. 申請が必要な場合、承認番号の表示方法についてもご教示ください

お手数をおかけしますが、よろしくお願いいたします。
```

**この文面で意図したこと**: 申請要否の分かれ目になりそうな3点（再配布しない／加工しない／
利用者自身の端末内のみ）を、聞かれる前にこちらから書いています。隠すと的外れな回答が
返るためです。
