# 0001. 地理院タイルのオフライン保存の可否

- **状態**: 決定
- **決めた日**: 2026-11-26
- **決めた人**: Holy-togikai（回答を受けて「進めたい」と判断）
- **関係するタスク**: T-001、T-002

## 何を決める必要があったか

山では電波が届かない場所が多く、オフラインで地図を見られることは登山アプリの
基本機能です。Phase 1 の最後に残っている項目でもあります。

しかし、地理院タイルを端末内に保存する行為は、**測量法上の「複製」に当たる可能性**が
あります。公式ページには「端末保存」「オフライン」「キャッシュ」を名指しした記述が
見つからず、自分たちで判断できませんでした。

これは法令の判断であり、**AIが決めてよいことではありません**。
国土地理院に直接問い合わせることにしました。

## 分かっていたこと（問い合わせ前）

| 事実 | 出典 |
|---|---|
| 申請不要とされているのは「リアルタイムに読み込んで表示する」場合のみ | 承認申請Q&A Q1-12 |
| 「地理院タイル等の基本測量成果を複製する場合には、デッドコピーであっても承認可能」 | 測量成果の複製及び使用の事例集 |
| 手数料は無料。標準処理期間は7〜14日（郵送期間と休日を除く） | 承認申請Q&A Q5-1 |
| 承認を得た場合、承認番号と出所を地図の表示中つねに画面に出す義務がある | 承認申請Q&A Q5-2 |

つまり「禁止されている」のではなく「**たぶん申請が要る、そして申請は通りうる**」
という見立てでした。

- **送信日**: 2026-11-17
- **窓口**: 国土地理院「基本測量成果の複製・使用申請についてのお問い合わせ」フォーム
  https://geoinfo2.gsi.go.jp/contact/Inquiry2.aspx?pcode=1005&bcode=100503&mcode=10050304
- **標準処理期間**: 7〜14日（郵送期間と休日を除く）。目安として 2026-11-24 〜 2026-12-01 ごろ

### 送った文面（原文）

```
件名: 地理院タイルを端末内に保存して利用する場合の承認申請の要否について

お世話になります。個人で iPhone 向けの登山アプリを開発しております。
地理院タイルの利用について、承認申請の要否をご教示ください。

【利用するタイル】
・標準地図（std）
・淡色地図（pale）
・写真（seamlessphoto）

【現在の利用方法】
国土地理院のサーバーからリアルタイムに読み込んで画面に表示しています。
画面左下に「地理院タイル」の出典表示を常時行い、地理院タイル一覧ページへの
リンクを付けています。この利用方法は、承認申請Q&A Q1-12 により申請不要と
理解しております。

【今後行いたい利用方法】
登山では電波の届かない場所が多いため、利用者が事前に範囲を指定して、
その範囲のタイルを端末内（アプリのデータ領域）に保存し、電波のない
山中でオフライン表示できるようにしたいと考えております。

・保存されるのは利用者自身の端末内のみで、第三者への再配布は行いません
・タイルの加工や改変は行いません（そのままの画像として保存・表示します）
・保存したタイルを別のサーバーへ転送することはありません
・アプリは App Store での公開を予定しております（無料／一部有料機能）

【お伺いしたいこと】
1. 上記のオフライン保存は、測量法に基づく承認申請が必要でしょうか
2. 必要な場合、第29条（複製）と第30条（使用）のどちらに当たりますでしょうか
3. 申請が必要な場合、承認番号の表示方法についてもご教示ください

お手数をおかけしますが、よろしくお願いいたします。
```

**この文面で意図したこと**: 申請要否の分かれ目になりそうな3点（再配布しない／加工しない／
利用者自身の端末内のみ）を、聞かれる前にこちらから書いています。隠すと的外れな回答が
返るためです。

### 回答の原文（質問の再掲部分は省略）

```
平素より国土地理院の測量行政・事業に御協力をいただき御礼申し上げます。

今回のケースにおいて、測量法に基づく基本測量成果の利用手続の観点からお問合せに以下回答します。
ただし、場合により回答が変わる可能性がありますこと、予め御了承ください。

■申請要否
端末内に保存された地図画像等が、利用者の私的利用に留まる場合、申請は不要です。

【私的利用と見做せる範囲】
　・地図画像等が公開または共有等されない
　・地図画像等を用いて別の成果物を生成しない

私的利用の範囲を超える場合、利用者からの申請が必要な場合がありますので、
貴アプリ上でもその旨記載いただけると幸いです。
申請の要否は、利用者にて以下の「利用手続」から確認してください。
　-国土地理院の地図の利用手続　　https://www.gsi.go.jp/common/000223838.pdf#page=2

■申請不要の場合の留意事項
1.　出典明示のうえ、国土地理院コンテンツ利用規約および個別の規約を遵守ください。
2.　地理院タイル利用時は、地理院タイル一覧の該当タイル備考欄記載事項も遵守ください。
なお、出典明示は御提示のものでも結構です。

　-出典の記載　　　　　https://www.gsi.go.jp/LAW/2930-meizi.html
　-コンテンツ利用規約　https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html
　-地理院タイル一覧　　https://maps.gsi.go.jp/development/ichiran.html

■サーバ負荷に関するお願い事項と留意点
サーバの負荷軽減にご配慮いただきながらの利用をお願いいたします。
状況に応じて、国土地理院の正常な運用を妨げる、またはその恐れが生じる程度の
負荷をサーバに与える通信に対して、個別に相談させていただく場合や、
予告なくアクセスの遮断を行う場合があります。
```

### 回答の読み方

| 問い | 答え |
|---|---|
| 1. オフライン保存に申請は要るか | **利用者の私的利用に留まるなら不要** |
| 2. 第29条か第30条か | 申請不要のため、問われなかった |
| 3. 承認番号の表示方法 | 申請不要のため、承認番号は無い。**出典表示は今のもの（「地理院タイル」＋一覧へのリンク）でよい** |

「私的利用」の条件は2つです。

- 保存した地図画像を**公開・共有しない**
- 保存した地図画像から**別の成果物を作らない**

注意: 回答には「場合により回答が変わる可能性があります」とあります。
使い方を広げるとき（下の「見直すとき」）は、改めて問い合わせてください。

## 決めたこと

**オフライン保存（T-002）に申請なしで着手する。ただし「私的利用」の枠から出ない作りにする。**

## なぜそう決めたか

回答が「申請不要」だったためです。このアプリの保存は、利用者自身の端末の中だけで、
加工も再配布もしません。回答の「私的利用」の2条件にそのまま当てはまります。

## この判断の結果どうなるか

### T-002 で守ること

| 守ること | 回答のどこから |
|---|---|
| 保存したタイルを、ほかの人と共有・書き出しする機能を作らない | 私的利用の条件「公開または共有等されない」 |
| 保存したタイルを加工・合成して別の画像やデータを作らない（そのまま表示するだけ） | 私的利用の条件「別の成果物を生成しない」 |
| **アプリ内に「私的利用の範囲を超える場合は申請が要ることがある」旨と、利用手続へのリンクを載せる** | 「貴アプリ上でもその旨記載いただけると幸いです」 |
| 出典表示（「地理院タイル」＋一覧へのリンク）をオフライン表示中も出し続ける | 留意事項1 |
| 地理院タイル一覧の、使うタイル（std / pale / seamlessphoto）の備考欄を確かめて守る | 留意事項2 |
| 一度に取りに行く量と速さを抑える（保存できる範囲・ズームの上限、同時接続数、間隔） | サーバ負荷のお願い。守らないと予告なく遮断されうる |

### できるようになったこと

- オフライン地図（T-002）に着手できる
- 承認番号を画面に出す改修は**要らない**

### この判断を見直すとき

次のどれかをするときは、私的利用の枠を超える可能性があるので、改めて国土地理院に問い合わせてください。

- 保存した地図を他の利用者と共有する（山行の共有、地図の書き出しなど）
- 保存した地図に軌跡などを重ねた画像を作って、書き出す・投稿する
- アプリ側でタイルをまとめて配る（サーバに置く、アプリに同梱する）
